# SQL Injection Scanner 🔐

A Python-based cybersecurity project that detects common SQL error indicators in simulated responses.

## Features
- Detects predefined SQL error patterns.
- Tests simulated responses.
- Generates JSON and CSV reports.

## Technologies
- Python
- Google Colab
- Regular Expressions

## How to Run
1. Open the notebook in Google Colab.
2. Run the code cells.
3. View the output and generated reports.

## Limitation
This is an offline prototype. It does not scan live websites or confirm actual vulnerabilities.
